# Model 8: baseline-plus-raw union shortlist

This paired experiment tests whether expanding Dalvin Model 3d's shortlist improves its complete open-set pipeline. It preserves PCA/LDA, mutual RootSIFT / partial-affine RANSAC, viewpoint features, three LightGBM components, three prediction-stacking stages and Dalvin's final unknown-probability rule. No nuisance projection or Model 5 score fusion is used.

## Shortlists

- Baseline: 15 identities ranked by `LDA_max + 0.05*tanh(SIFT_max/15)`.
- Union: retain those 15 in their original order, then append distinct identities from the raw cosine top 15, in raw rank order. Each query has 15–30 valid candidates.

The implementation uses 30 internal slots for union frames, with an explicit validity mask. Padding rows are excluded from candidate training, their probabilities are zeroed before normalization and stacking, and they receive negative-infinite scores during final ranking. No mask column is supplied to a learner. The original candidate-rank feature is retained; appended candidates have ranks 15 and above. All three models in each stage are trained separately for each variant.

## Fixed comparison

Seed 2052 matches the existing Model 7 baseline protocol and compatible SIFT cache. Within each species, 20% of identities are reserved for validation, 20% remain unused, and three non-overlapping 20% groups train successive stages. Each stage uses 12 simulated open-set episodes. Candidate scorers use 400 trees, the unknown detector 300; learning settings are identical. Each variant receives its own previous-stage predictions. Feature extraction is shared: the union frame's first 15 rows per query exactly reproduce the baseline frame.

Validation episode seeds 22052, 22053 and 22054 were fixed before this run's outcomes. Each includes known queries plus identities wholly absent from the gallery. Near-duplicate groups are kept together using the baseline's cosine/SIFT regimes. PCA sees unlabelled queries, as in Dalvin's code; LDA sees gallery labels. RootSIFT verification uses 150 same-species neighbours, mutual nearest matching with a forward 0.85 ratio test, and 15-pixel RANSAC. The same role-local SIFT evidence is used by both methods.

The primary measure is pooled open-set MAP@5, with separate known and unknown scores, per-episode and per-species results. Predeclared slices are:

- Missing side: a known left/right query with no same-flank photo of the correct identity in the gallery. Front/back/up/down and missing-view queries do not enter this slice.
- Small gallery: a known query with one to three photos of its true identity in the gallery.
- Their intersection, same-side queries, larger galleries, and missing-view queries.

Report unique queries/identities as well as query appearances. Three episodes can reuse photos and identities. Descriptive uncertainty uses 3,000 paired bootstrap draws clustered by true identity, stratified by species. This does not account for variation from retraining models on new splits. The pass gate requires positive pooled and each-episode differences and no decline in known- or unknown-query MAP@5. Targeted-slice outcomes must still be considered separately.

These data were previously examined in EDA. This is a fixed, controlled experiment, not a pristine unseen dataset, a reproduction of the teammate's full-data training protocol, or a Kaggle leaderboard claim. Model 7's identity-disjoint stage protocol has smaller galleries than final competition inference.

## Run and resume

From the repository root:

```powershell
python Models/Abhay/Model8/test_union.py
python -u Models/Abhay/Model8/union_eval.py
```

Defaults use the supplied Downloads data and the existing `Model7/local_runs/paired_2052` SIFT cache. The cache is copied to this experiment's own output directory before use. Checkpoints are saved atomically after each stage; rerunning resumes completed stages. `--data`, `--cache-source`, `--output` and `--workers` override paths or concurrency. The seed, episode count and model settings remain fixed. Configuration mismatches refuse to reuse a run directory.

`local_runs/union_2052` contains configuration, source hashes, identity assignments, episode assignments, stage models, per-query predictions, candidate counts, final unknown probabilities and slice metrics. No competition submission is generated by this runner.
